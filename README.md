# OOP Assignment 02 – C++

## 📌 Project Overview

This repository contains **OOP Assignment 02** developed in C++.

The assignment focuses on basic Object-Oriented Programming concepts such as:

* Classes and Objects
* Private Data Members
* Public Member Functions
* Access Modifiers
* User Input
* `for` Loop
* Function Overloading

## 📂 Questions Covered

### Q1 – Employee Management

An `Employee` class is created with:

* Employee ID
* Employee Name
* Employee Salary

The program asks the user for the number of employees and uses a `for` loop to enter and display each employee's information.

### Q2 – Book Management

A `Book` class is created with:

* Book ID
* Book Title
* Author

The program demonstrates **function overloading** using two versions of the `setData()` function:

1. `setData(bookID, title, author)`
2. `setData(bookID, title)`

If the author name is not provided, the program stores **"Unknown"** as the author.

The purpose of this assignment is to understand:
